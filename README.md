## 💡 ภาพรวมโปรเจกต์

**GlobalByte Projects — Project Voting Portal** คือเว็บแอปพลิเคชันแบบ Front-End สำเร็จรูป (Zero-Dependency) สำหรับรวบรวม ค้นหา จัดอันดับ และกดโหวตไอเดียโครงงานด้าน **AI, IoT, ฮาร์ดแวร์ และงานพิมพ์ 3 มิติ** จำนวน **46 โปรเจกต์** พร้อมภาพประกอบครบทุกการ์ดและลิงก์ไปยังแหล่งอ้างอิงจริง

## ✨ ฟีเจอร์เด่น

- 🔍 **ค้นหาแบบ Real-Time:** พิมพ์ค้นหาจากชื่อโครงงานและคำอธิบายได้ทันทีโดยไม่ต้องรีโหลดหน้า
- 🏷️ **กรองตามหมวดหมู่ 7 หมวด:** สลับดูเฉพาะหมวด `AI`, `ESP32`, `Raspberry Pi`, `Arduino`, `Sensors`, `IoT`, `3D Print` หรือดูทั้งหมด
- 🔃 **จัดเรียงได้หลายรูปแบบ:** เรียงตามค่าเริ่มต้น, คะแนนโหวตสูงสุด หรือเรียงตามตัวอักษร (รองรับการเรียงภาษาไทย `localeCompare('th')`)
- 👍 **ระบบกดโหวต & ยกเลิกโหวต:** บันทึกผลโหวตลง `localStorage` ในเบราว์เซอร์อัตโนมัติ พร้อมอัปเดตตัวเลขทันที
- 🔗 **เปิดดูต้นฉบับโครงงาน:** คลิกการ์ดเพื่อเปิดหน้าอ้างอิงโครงงานในแท็บใหม่
- ⚡ **Zero-Build พร้อมใช้ทันที:** ใช้เพียง HTML + CSS + Vanilla JavaScript ล้วน ไม่ต้องติดตั้ง Node.js หรือฐานข้อมูล

## 🚀 วิธีดาวน์โหลดและเปิดใช้งานทันที

### วิธีที่ 1: เปิดออนไลน์ผ่าน GitHub Pages (แนะนำ ⚡)
👉 [https://newsoyes.github.io/IDIE_PROJECT_IOT/](https://newsoyes.github.io/IDIE_PROJECT_IOT/)

### วิธีที่ 2: โหลดไปเปิดในเครื่องด้วย 1 คลิก (Windows)
1. กดปุ่ม **Code → Download ZIP** แล้วแตกไฟล์
2. ดับเบิลคลิกไฟล์ **`open-web.bat`** หรือไฟล์ **`index.html`** เพื่อเปิดในเบราว์เซอร์ได้ทันที!

### วิธีที่ 3: โคลนผ่าน Git
```bash
git clone https://github.com/newsoyes/IDIE_PROJECT_IOT.git
cd IDIE_PROJECT_IOT
# เปิดไฟล์ index.html หรือรัน python -m http.server 8000
```
